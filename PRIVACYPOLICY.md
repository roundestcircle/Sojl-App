# Datenschutzerklärung

**App:** Sojl (`com.bertibertsorganization.sojlapp.beta`)
**Stand:** 16.08.2026

## Keine Datenerhebung

Sojl erhebt, speichert, überträgt und teilt keinerlei personenbezogene Daten.

- Keine Benutzerkonten, keine Registrierung, keine Anmeldung.
- Keine Analyse, kein Tracking, keine Werbung, keine Absturzberichte.
- Es werden keine Daten an uns oder an Dritte übermittelt.

## Standortberechtigung

Die App kann den Zugriff auf den Standort anfragen, um die aktuelle Position für
ihre bodenkundlichen Funktionen zu bestimmen. Diese Standortdaten werden
ausschließlich auf dem Gerät verwendet. Sie werden nicht hochgeladen, nicht auf
einem Server gespeichert und nicht an Dritte weitergegeben.

## Kinder

Die App erhebt von niemandem Daten, auch nicht von Kindern.

## Änderungen

Sollte sich diese Erklärung ändern, wird die aktualisierte Fassung zusammen mit
der App in diesem Repository veröffentlicht.
